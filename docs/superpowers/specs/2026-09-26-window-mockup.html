Settings

Sidebar (nixi's top bar, moved)

  • Start / Stop: one large button; turns red while running
  • Direction: I speak / Others / Both (Both runs two Gemini sessions, started 300 ms apart)
  • Languages: one pair, mirrored automatically for the other direction; "Auto-detect" only for the source language
  • Outputs: Chatbox and Translated voice; the wrist overlay and its fine-tune panel slot in here after v1
  • Footer: API key status (a link to get a key when missing) and Settings

Main area (nixi's chat view)

  • Right bubbles are yours, left are other players'; small original line above the large translation
  • Text still being translated updates in place with a cursor (bottom bubble)
  • Typing bar: Enter sends and Esc clears; greyed out when the direction is "Others"
  • Status bar: state dot and latest status on the left, count and latency on the right

  • ☕ Sponsor button (nixi's personal donation links)
